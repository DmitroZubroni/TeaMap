# 茶 · Tea Atlas (Атлас чая)

> **Интерактивный географический атлас терруаров, регионов и сортов чая со всего мира.**  
> *React 18 · Vite · MapLibre GL (WebGL) · Tailwind CSS · Двуязычный (RU/EN)*

---

## О проекте

**Tea Atlas** — это независимый открытый проект, созданный для визуализации мировой чайной географии. 

В отличие от стандартных каталогов магазинов и кафе, Tea Atlas задуман как **винный атлас, но для чая** (подобно фундаментальным атласам терруаров *The World Atlas of Wine*). Проект исследует чай как терруарный продукт: связывает сорт с высотой произрастания, климатом горных долин, ботаническим культиваром, традицией прожарки и органолептическим профилем.

В атлас занесены **8 ключевых чаепроизводящих стран**, десятки горных хребтов и **97 аутентичных сортов чая** с подробными технологическими и дегустационными карточками на двух языках (русском и английском).

## Ключевой функционал

### 1. 3-уровневая пространственная навигация (Масштабирование терруара)
Камера карты динамически переключает режимы отображения в зависимости от зума:
1. **Мир (World View, `zoom ≤ 3.2`):**
   * Обзор планеты с интерактивными пинами стран-производителей.
   * Отображение флагов, названий и количества доступных сортов.
2. **Страна (Country View, `3.2 < zoom ≤ 6.4`):**
   * Фокусировка на чайных провинциях и префектурах выбранной страны.
   * Отображение меток горных массивов, долин и чайных регионов (например, *Уишань, Алишань, Долина Брахмапутры, Сиху, Ува*).
3. **Регион и Точки сбора (Region & Tea View, `zoom > 6.4`):**
   * Высокоточная детализация до отдельных гор, деревень и плантаций.
   * Отображение пинов конкретных сортов чая с автоматическим включением текстовых бейджей на высоком приближении.

### 2. Цветовая кодировка по цвету чайного настоя
Все метки на карте окрашены не случайным образом, а строго в соответствии с **реальным цветом настоя (liquor color)** готового напитка для 9 чайных категорий:
* ⚪ Белый чай (`liquor.white`)
* 🟢 Зелёный чай (`liquor.green`)
* 🟡 Жёлтый чай (`liquor.yellow`)
* 🟠 Светлый улун (`liquor.oolong_light`)
* 🟤 Тёмный улун / Уишаньский яньча (`liquor.oolong_dark`)
* 🔴 Красный / Чёрный чай (`liquor.red`)
* 🟫 Шэн пуэр (`liquor.dark_sheng`)
* ☕ Шу пуэр (`liquor.dark_shu`)
* 🪵 Хэй ча / Выдержанный чай (`liquor.dark_other`)

### 3. Интерактивный сайдбар (3 рабочих режима)
Сайдбар адаптируется под экраны любых размеров (от мобильных телефонов до 4K-мониторов):
* **Вкладка «Навигация»:** иерархический каталог со сквозными кликабельными хлебными крошками (`Мир / Страна / Регион`). Позволяет перемещаться по атласу без прямого взаимодействия с картой.
* **Вкладка «Справочник»:** 
  * Интерактивная легенда и фильтр по категориям: клик по категории мгновенно скрывает или возвращает соответствующие точки на карте.
  * Глобальный живой поиск с дебаунсом (300 мс) по всей базе чаёв всех 8 стран (ищет по оригинальному названию, транслитерации, иероглифам, региону и культивару).
* **Вкладка «Избранное»:** персональная коллекция понравившихся чаёв с сохранением состояния в `localStorage`.

### 4. Исчерпывающая карточка чая (`TeaPanel`)
При клике на любую чайную точку на карте или в меню открывается выдвижная карточка:
* **Географическая шапка:** страна, провинция, горный массив, точные координаты и высота над уровнем моря (altitude).
* **Технические параметры заваривания:** рекомендованная температура воды (°C), граммовка листа на объём, подходящая посуда (гайвань, исинский чайник, стекло) и потенциал проливов.
* **Органолептическая матрица:** описание сухого листа, цвета настоя, аромата, вкуса и послевкусия.
* **Ботаника и обработка:** используемый культивар (вариетет куста), процент ферментации/окисления, степень прогрева (прожарки) и сезон сбора.
* **История и мифология:** этимология названия, историческая хроника, современный статус сорта и блок любопытных фактов.
* **Связанные сорта (`relatedTeas`):** быстрый переход к родственным по вкусу или региону чаям.
* **Кнопка «В избранное»:** добавление в персональный список одним кликом.

### 5. Полная двуязычность (RU / EN) и локализация
* Полный перевод интерфейса и всей базы данных (все 116 JSON-файлов для всех 8 стран).
* Переключатель языка (`RU` / `EN`) в шапке сайдбара.
* Синхронное обновление `document.title`, мета-тегов `description`, ключевых слов и OpenGraph-тегов под активный язык.
* Двухуровневый каскад отказоустойчивости данных: запрос в GitHub-репозиторий базы ⭢ локальный кэшированный оффлайн-бандл (`/public/tea-data/`) ⭢ фоллбэк на альтернативный язык.

### 6. Поддержка проекта («Угостить чаем» / CloudTips)
* Кнопка в подвале сайдбара и плавающая кнопка в мобильном режиме.
* Аутентичная векторная иконка **традиционной пиалы без ручки** (`PialaIcon`).
* Модальное окно с описанием некоммерческой миссии атласа и интеграцией со страницей CloudTips (СБП, T-Pay, СберPay, банковские карты).
* Управление с клавиатуры (`Escape`), фокус-трап и закрытие по клику на оверлей.

```
│              ▲                               ▲              │
│              │                               │              │

│    (Pre-baked Vector)                        ▲              │
└──────────────┼───────────────────────────────┼──────────────┘

    (MVT Tiles + Glyphs)           2) Local Bundle (/tea-data/)
```

* **React 18 (Hooks, Suspense, Lazy, Context API):** компонентный каркас с чистым разделением состояний.
* **MapLibre GL:** высокопроизводительный движок рендеринга векторных карт на базе WebGL. Использует векторные тайлы OpenMapTiles / CARTO Positron без необходимости в платных ключах (Mapbox Token).
* **Tailwind CSS:** кастомная дизайн-система в восточной эстетике:
  * `ink` (`#1C2A22`) — глубокая китайская тушь;
  * `porcelain` (`#F3EEE0`) — тёплый матовый фарфор;
  * `gold` (`#C08A34`) — благородное сусальное золото;
  * `jade` (`#4F6F52`) — мягкий нефрит.
  * Шрифты: антиква **Fraunces** для чайных заголовков, гротеск **Inter** для интерфейса, **IBM Plex Mono** для высот, температур и граммовок.
* **Query-based Routing:** маршрутизация построена на параметрах строки запроса (`?country=china&region=wuyi&tea=da_hong_pao`). Это позволяет делиться ссылками на конкретный чай или регион без необходимости настраивать `history fallback` на статическом сервере.

## Инженерные и интерфейсные особенности

### Кинематографичные перелёты камеры
Вместо стандартного линейного зума движение камеры реализовано через функцию плавности `easeInOutCubic`:
$$\text{easing}(t) = \begin{cases} 4t^3, & t < 0.5 \\ 1 - \frac{(-2t + 2)^3}{2}, & t \ge 0.5 \end{cases}$$
При перемещении между удалёнными точками камера делает парящую дугу (`curve: 1.35 – 1.5`), приподнимаясь над рельефом и плавно опускаясь в горную долину. На десктопе в `fitBounds` учтена ширина сайдбара (`padding.left: 320px`), благодаря чему страна или регион центрируются строго в видимой области экрана правее меню.

### Алгоритм веерной дисперсии точек с одинаковыми координатами
В реальных данных плантаций несколько сортов чая часто происходят из одной точки (одна вершина горы, монастырь или фабрика). Чтобы точки не перекрывали друг друга намертво, написан алгоритм круговой дисперсии:
* Точки с одинаковыми координатами группируются;
* Если в группе $> 1$ чая, они автоматически разводятся по кругу с малым угловым сдвигом ($\Delta = 0.006^{\circ}$):
  $$\text{lat}_i = \text{lat}_0 + \Delta \cdot \sin\left(\frac{2\pi i}{N}\right), \quad \text{lng}_i = \text{lng}_0 + \Delta \cdot \cos\left(\frac{2\pi i}{N}\right)$$
* На общем плане они выглядят как аккуратное созвездие одного региона, а при зуме каждую точку можно легко выделить и нажать.

### Оптимизация скорости загрузки карты в 3 раза
1. **Предзапечённый стиль (`/public/map/style.json`):** оригинальный стиль CARTO облегчён со 107 КБ до 40 КБ. В него заранее зашиты все цвета чайной палитры и прямые адреса тайловых серверов. Это устранило лишний HTTP-запрос за `tiles.json` и исключило тяжелый цикл вызовов `map.setPaintProperty` в рантайме.
2. **Мгновенный рендер (`fadeDuration: 0`):** отключена искусственная анимация 300-мс проявления тайлов. Векторные тайлы и символы отрисовываются в тот же кадр, когда пришли по сети.
3. **Параллельная предзагрузка:** вызов `import('./components/MapView')` стартует на этапе инициализации модуля `App.jsx`, параллельно с разбором DOM.
4. **Preload & DNS-Prefetch:** в `index.html` прописаны `preload` для файла стиля и предварительное разрешение DNS для тайловых серверов.

## Запуск и разработка

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки
npm run dev
# Сервер запустится по адресу: http://localhost:5173

# 3. Продакшн-сборка
npm run build
# Оптимизированный бандл будет создан в папке dist/

# 4. Локальный предпросмотр продакшн-сборки
npm run preview
```

## Развёртывание (Deployment)

Приложение полностью статическое (SPA) и готово к бесплатному деплою на любой хостинг:
* **Vercel / Netlify / Cloudflare Pages:**
  * Build command: `npm run build`
  * Output directory: `dist`
* **GitHub Pages:**
  * Можно собирать через GitHub Actions и деплоить ветку `gh-pages` или артефакт сборки `dist`.
